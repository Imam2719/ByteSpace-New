ByteSpace New


===

# A responsive landing page for \*\*ByteSpace\*\*, an online learning platform, built from the provided Figma design.

# 

# \*\*Live Demo:\*\* https://bytespace-new-tawny.vercel.app/

# \*\*Design (Figma):\*\* https://www.figma.com/design/26TBgRjmpuxudcErJsHUfy/ByteSpace-New-Check-website?node-id=0-1\&p=f\&t=eQOrqJmq6rMG5b6L-0 


## Pages
===

# \- Landing page (`index.html`)

# \- Sign in (`signin.html`) and Sign up (`signup.html`)

# \- Courses (`courses.html`) and Course details (`course.html`)

# \- Creator (`creator.html`)

# \- 404 page (`404.html`)

# 

# \## Tech Stack

# \- HTML5

# \- CSS3

# \- JavaScript (vanilla)

# \- Tailwind CSS (CDN)

# \- Google Fonts (Outfit, Poppins)

# \- Deployed on Vercel

# 

# \## Run Locally

# ```bash

# git clone https://github.com/Imam2719/ByteSpace-New.git

# cd ByteSpace-New

# ```

# Open `index.html` in your browser, or use the VS Code Live Server extension.

# 

# \## Notes

# \- Best viewed at desktop width (1440px); it scales down on smaller screens.

# \- Some landing page sections are based on Figma-exported frames with clickable HTML areas on top. The testimonials section is built as real HTML.
